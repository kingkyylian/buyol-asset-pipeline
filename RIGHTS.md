# Rights And Reuse

This repository is a public research archive for Buyol asset-generation work. It
is not a reusable asset pack and it does not grant a general open-source license.

Unless a specific file says otherwise:

- generated images, Blender files, model exports, reference images, and visual
  assets are all rights reserved
- do not reuse, redistribute, resell, upload, or train on the assets
- do not treat the repository as production-ready source material
- workflow notes and prompts are published for inspection and traceability only

If this repository is later split into a small public showcase, reusable source
code and generated assets should receive separate, explicit licenses.
